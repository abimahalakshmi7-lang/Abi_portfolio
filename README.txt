ABI PREMIUM PORTFOLIO
======================

Files:
- index.html
- style.css
- script.js
- assets/robot-hi.gif
- assets/*.png

How to run:
1. Extract the ZIP.
2. Open index.html directly in a browser, or use VS Code Live Server.
3. Edit the content in index.html to update links/details.

The portfolio is based on the supplied resume and includes:
- Animated hero robot saying Hi
- Premium dark + cyan/purple gradient visual system
- Scroll reveal animations
- Floating AI/tech PNG icons
- Responsive mobile navigation
- About, Skills, Experience, Projects, Education, Certifications and Contact sections
- LinkedIn, HackerRank and email CTAs
